# NASU Blood Donation Campaign

Interactive web project workspace for the NASU Blood Donation Campaign.

## Stack

- Next.js 16 (App Router)
- React 19 + TypeScript (strict)
- Tailwind CSS v4
- Framer Motion + Lucide React

## Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Verification

```bash
npm run typecheck
npm run lint
npm run build
```
